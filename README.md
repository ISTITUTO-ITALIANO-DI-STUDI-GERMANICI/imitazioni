# imitazioni
Un progetto di edizioni scientifiche digitali delle traduzioni di Attilio Bertolucci.

Imitazioni is a digital scholarly edition of Attilio Bertolucci’s English and French translations (1934–1994). It investigates translation as a generative space of writing, tracing formal changes across manuscript, typescript, and print in relation to Bertolucci's poetic work.

Developed within the DiScEPT framework, the project combines semantic modeling, visualizations, and Source → Target alignments to analyse textual variation and the role of translation in Bertolucci’s poetics.
