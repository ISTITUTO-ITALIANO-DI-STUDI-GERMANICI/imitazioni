07 / 36 · OBJECTS OF STUDY

Three kinds of evidence

A translation is not just a source poem paired with a published Italian text

Published Italian versions

The poetic forms Bertolucci decided to publish; bibliographical history and possible later revisions.

Multiple source expressions

Different versions and printings may diverge. An editorial reference does not demonstrate which book Bertolucci used.

Manuscripts and drafts

Material documents can reveal deletions, substitutions and unfinished alternatives—not only final equivalences.

Together: original → translation → revision → poetic writing, with each inference linked to identifiable evidence.

19 / 36 · DiScEPT

Smart Align: what it does

How sentence embeddings and order-preserving dynamic programming produce candidate links

● 100% client-side · No text sent to a server · Hugging Face model cached locally
01 · INPUT

TEI units

Read the selected verses, sentences or paragraphs from each document.

02 · EMBEDDINGS

Dense vectors

A multilingual sentence model encodes each element as a numerical representation.

03 · SIMILARITY

Cosine matrix

Calculate semantic similarity for every source–target pair.

04 · SEQUENCE

Dynamic programming

Choose the best monotone, order-preserving sequence; skip low-scoring pairs.

ALGORITHM

Needleman–Wunsch-like alignment

Optimises total similarity while preserving textual order. If source element i matches target j, later matches cannot move backwards. Complexity: O(n × m) for n and m units.

EDITORIAL CONTROL

Candidates, not conclusions

Similarity does not prove equivalence or source attribution. Researchers inspect uncertain results, revise links and preserve the validated TEI stand-off output.

Privacy by design: inference runs in the browser; the model is downloaded on first use and cached. The supplied documentation states that no source or target text is sent to the server.

Smart Align: sentence and word models

Available multilingual models and the separate word-alignment architecture

Sentence modelDownloadLanguagesQuality / speedSuggested use
MiniLM L12Xenova/paraphrase-multilingual-MiniLM-L12-v2~120 MB50Good · FastCommon European languages (EN, IT, DE, FR…)

LaBSEXenova/LaBSE~500 MB109High · ModerateLanguage-agnostic multilingual matching
A DIFFERENT MODEL FOR WORDS

awesome-align · multilingual BERT

When aligned verses contain TEI <w> tokens, a masked-language model uses intermediate layer 8 representations, not sentence embeddings. The default fine-tuned model (~143 MB) is loaded only when needed.

WORD LINKING RULE

Mutual best match + threshold

Two words are linked if each is the other's strongest match and similarity exceeds a threshold. Precision is prioritised over coverage: unmatched words remain unlinked. This can handle reordered words.

Methodological caution: language counts and quality/speed are indicative model descriptions, not guaranteed quality for historical varieties. Review is essential for poetry and Dante's Italian.
